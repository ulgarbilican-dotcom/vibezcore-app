## Voor de app
(bv. App Store Connect → "App Review Information", of interne notitie bij
een submission — legt aan een Apple-reviewer uit waarom de app bewust
dark-only is en aan de HIG-contrastregels voldoet.)

> VIBEZCORE ships with a single dark theme by design. Background (#0a0a0a)
> and primary text (#f4f4f4) exceed the 4.5:1 contrast ratio required by
> Apple's Human Interface Guidelines for Dark Mode. Large surfaces (cards,
> panels) use dark neutrals with thin accent-colored borders rather than
> solid accent fills, keeping the interface comfortable in low-light use —
> the app's primary context for breathwork and focus sessions.

## Voor de website
(marketing-copy, bv. een regel op een about/design-pagina — legt de
dark-esthetiek uit als bewuste merkkeuze, niet als technische noodzaak.)

> VIBEZCORE is built for dark. Every screen is designed against a
> near-black background, so the interface never fights the mood of a
> focus or breathwork session — no glare, no distraction, just enough
> contrast to read comfortably in any light.
